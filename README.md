AI 문진 서비스

AI와의 대화를 통해 환자의 증상을 사전에 정리하고, 의료진의 문진 및 정보 확인을 보조하는 서비스

📌 Overview

병원 방문 전 환자가 AI와 자연어로 문진을 진행하고,
수집된 내용을 바탕으로 의료진이 환자의 주요 증상과 문진 결과를 빠르게 확인할 수 있도록 돕는 서비스입니다.

단순한 AI 챗봇이 아니라 문진 세션과 대화 이력을 데이터로 관리하고, AI 요약 및 의료진 대시보드로 연결하는 것​을 목표로 합니다.

✨ Features
🤖 AI 문진

환자가 AI와 대화하며 증상 및 관련 정보를 입력합니다.

📝 AI 요약

문진 과정에서 수집된 정보를 의료진이 빠르게 확인할 수 있도록 요약합니다.

🩺 의료진 대시보드

환자의 문진 결과와 AI 요약 정보를 확인할 수 있습니다.

🔐 사용자 인증

Supabase Auth를 기반으로 환자와 의료진의 역할을 구분합니다.
